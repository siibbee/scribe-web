# Scribe Web Platform

Scribe, modern ve edebi bir dijital hikaye okuma ve yazma web platformudur.

## Proje Yapısı

- `story-frontend/`: React + Vite + Vanilla CSS ile geliştirilmiş modern, responsive web arayüzü (Terracotta Warm teması, karanlık mod, kütüphane tür filtreleri, noktalardan ayrılan yorum sistemi).
- `story-app-backend/`: Node.js, Express, Neon PostgreSQL ve Cloudinary ile geliştirilmiş RESTful API sunucusu.
